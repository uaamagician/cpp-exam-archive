## 一定要會的語法

**拷貝建構元與 `=`**
```cpp
class CVec2 {
    float x, y;
public:
    CVec2(float _x = 1.0f, float _y = 1.0f) : x(_x), y(_y) {}
    CVec2(const CVec2 &v) { cout << "拷貝建構元被呼叫\n"; x = v.x; y = v.y; }   // 題目指定的輸出要保留
    CVec2 &operator=(const CVec2 &v) { x = v.x; y = v.y; return *this; }
    CVec2 operator-(const CVec2 &v) const { return CVec2(x - v.x, y - v.y); }
    CVec2 operator*(float k) const { return CVec2(x * k, y * k); }
    friend CVec2 operator*(float k, const CVec2 &v) { return CVec2(v.x * k, v.y * k); }
};
```
- 呼叫時機：`CVec2 b = a;`、函式以「值」傳入物件、回傳物件時都會呼叫拷貝建構元。

**繼承與 `protected`**
```cpp
class CCharacter {
protected:                                   // 子類別可以直接用，外部不行
    int x, y, color;
public:
    CCharacter(int _x = 0, int _y = 0, int _c = COLOR_LIGHTGREEN) : x(_x), y(_y), color(_c) {}
    CCharacter(const CCharacter &c) : x(c.x), y(c.y), color(c.color) {}
    virtual ~CCharacter() { cout << "CCharacter 解構元\n"; }
    virtual void draw() = 0;                 // 純虛擬函式：這個類別不能直接宣告物件
};
class CHero : public CCharacter {
public:
    CHero(int _x, int _y, int _c) : CCharacter(_x, _y, _c) {}          // 子類別建構元呼叫父類別建構元
    CHero(const CHero &h) : CCharacter(h) { }                           // 拷貝建構元也要呼叫父類別的
    ~CHero() { cout << "CHero 解構元\n"; }
    void draw() { /* 畫自己 */ }
};
```
- 初始化列表 `: x(_x)` 的寫法要熟；建構元的執行順序是「父類別 → 子類別」，解構元是「子類別 → 父類別」。

**多型：父類別指標指向子類別物件**
```cpp
CCharacter *p = new CHero(0, -200, 13);
p->draw();                  // 因為 draw 是 virtual，會執行 CHero::draw
delete p;                   // 父類別解構元必須是 virtual，否則子類別解構元不會被呼叫
```

**物件指標與鏈結串列**
```cpp
struct tNode { CCharacter *obj; tNode *next; };
// 走訪：while (p) { p->obj->draw(); p = p->next; }
// 釋放：先 delete 節點內的 obj，再 delete 節點本身
```

**物件間資料傳遞（`target`）**
```cpp
class CMouse {
    int x, y, color; bool btracer; CMouse *target;
public:
    void setTarget(CMouse *t) { target = t; }
    void update() { if (btracer && target) { x = target->x; y = target->y; } }
};
```

**`static` 成員**
```cpp
class CBox {
    int _size;
    static int count;                        // 記錄已建立幾個物件
public:
    CBox(int s) { _size = s; count++; }
    ~CBox() { count--; }
    static void showCount() { cout << count; }
};
int CBox::count = 0;                         // 類別外定義
```

**分檔**
```cpp
// cmouse.h     只放 class 的定義、成員函式宣告（不得有函式主體）
// cmouse.cpp   #include "cmouse.h"，所有成員函式寫成 void CMouse::draw() { ... }
// p7.cpp       #include "cmouse.h"，放 main 與主程式要用的函式
```
- `.h` 要加防重複包含：`#pragma once` 或 `#ifndef ... #define ... #endif`。

## 常見失分點
- 父類別解構元沒加 `virtual`，透過父類別指標 `delete` 時子類別資源沒釋放。
- 子類別建構元 / 拷貝建構元忘了呼叫父類別對應的版本。
- 純虛擬函式寫成 `virtual void draw();`（少了 `= 0`）。
- `protected` 與 `private` 搞混，子類別存取不到。
- 釋放鏈結串列時只釋放節點，沒有釋放節點裡的物件。
- 分檔時 `.h` 裡放了函式主體，或 `.cpp` 少了 `#include`。
- 題目指定的輸出文字（例如「拷貝建構元被呼叫」）被改掉或忘了印。
