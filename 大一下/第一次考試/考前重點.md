## 一定要會的語法

**結構與巢狀結構**
```cpp
struct sShape  { int x, y, r, g, b; };
struct sCircle { sShape info; int radius; };          // 巢狀：cx[i].info.x
sCircle cx[5];
```

**指標：`.` 與 `->`**
```cpp
sCircle *pc = &cx[0];
pc->radius = 10;          // 等同 (*pc).radius
pc[2].radius = 5;         // 指標也可以當陣列用
```

**傳陣列、傳指標、傳參照**
```cpp
void genCircles(sCircle cx[], int n);      // 傳陣列：函式內改了，原陣列也會變
void drawC(sCircle *pc);                    // 傳指標：drawC(&cx[i]);
void genC(sCircle &c, int n);               // 傳參照：genC(cx[i], i);
```

**動態記憶體**
```cpp
sCircle *pc = (sCircle *)malloc(sizeof(sCircle) * 5);   // C 寫法
free(pc);
sCircle *pc2 = new sCircle[5];                           // C++ 寫法
delete[] pc2;                                            // 陣列用 delete[]
```
- 指定「全部都要用指標寫法」時，不要偷偷用陣列下標以外的變數名稱混著用。

**讀檔（題目常見做法）**
```cpp
FILE *pfile = fopen("circles.txt", "r");
int n;
fscanf(pfile, "%d", &n);                       // 先讀第一筆：圓的個數
for (i = 0; i < n; i++)                        // 迴圈終止條件必須是剛讀到的 n
    fscanf(pfile, "%s %d %d %d %d %d %d", c[i].name, &c[i].x, &c[i].y, ...);
fclose(pfile);
// 一直讀到檔尾：while (!feof(pfile)) { ... }
```
- 讀 `story.txt` 統計字母：一個字元一個字元讀（`fgetc` / `fscanf("%c")`），用 `isalpha`、`tolower` 或自己比較範圍，累加到 `int cnt[26]`。
- 不可修改 `circles.txt` 的資料。

**鏈結串列**
```cpp
struct tNode { int n; tNode *next; };
// 四個變數串起來
n1.next = &n2; n2.next = &n3; n3.next = &n4; n4.next = NULL;
tNode *p = &n1;
while (p != NULL) { printf("%d ", p->n); p = p->next; }

// 動態建立 + 釋放
tNode *head = NULL, *tail = NULL;
for (i = 0; i < cnt; i++) {
    tNode *t = (tNode *)malloc(sizeof(tNode));
    scanf("%d", &t->n); t->next = NULL;
    if (head == NULL) head = tail = t; else { tail->next = t; tail = t; }
}
while (head != NULL) { tNode *d = head; head = head->next; free(d); }   // 先記住再釋放
// 插入：先找到插入位置的前一個節點 p，newNode->next = p->next; p->next = newNode;
```

**函式多載與預設引數**
```cpp
void pc(int n);                              // 同名函式，靠引數個數 / 型別區分
void pc(char ch, int n);
void pc(char ch, int e, int s = 1);          // 預設值只能寫在宣告，而且要從右邊往左給
```

## 常見失分點
- 釋放鏈結串列時先 `free` 了節點才去讀 `->next`。
- 讀檔的迴圈終止條件沒有用第一筆讀到的個數。
- `malloc` 之後忘了判斷、或 `free` 漏掉；陣列版 `new[]` 用成 `delete`。
- 傳指標時忘了取址 `&`；傳結構陣列元素時混淆 `.` 與 `->`。
- 預設引數寫在定義與宣告兩個地方。
