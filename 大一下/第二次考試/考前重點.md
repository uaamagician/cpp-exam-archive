## 一定要會的語法

**類別基本寫法**
```cpp
class CMouse {
private:
    int x, y, color, status;
public:
    CMouse(int _x = 0, int _y = 0, int _c = COLOR_WHITE) { x = _x; y = _y; color = _c; status = 1; }   // 預設引數
    int  getStatus() { return status; }
    void draw();
};
void CMouse::draw() { /* 寫在類別外要加 CMouse:: */ }
```
- 私有成員只能用成員函式存取；題目要求「私有」就一定要放在 `private:`。

**建構元多載（不用預設引數時）**：同一個類別寫多個同名建構元，引數個數不同（例如 `CMouse(int color)`、`CMouse(int x, int y)`），每個建構元都要把其他成員設好初始值。

**`static` 成員**
```cpp
class CMouse {
public:
    static int si;                           // 宣告
    static void showTotalCount();
};
int CMouse::si = 0;                           // 一定要在類別外定義一次
```

**運算子多載**
```cpp
class CVec2 {
    float x, y;
public:
    CVec2(float _x = 1.0f, float _y = 1.0f) { x = _x; y = _y; }
    CVec2 operator+(const CVec2 &v) { return CVec2(x + v.x, y + v.y); }
    bool  operator<(float ff)       { return _iw < ff; }
    friend bool operator<(float ff, const CMouse &m) { return ff < m._iw; }   // 數值在左邊要寫 friend
};
```
- 「物件 < 物件」「物件 < 數值」「數值 < 物件」是三個不同的函式。

**類別內有指標成員時**：建構元用 `new` 取得，解構元用 `delete` 釋放（`new[]` 要配 `delete[]`）。

**`cout` 格式化（要 `#include <iomanip>`）**
```cpp
cout << setw(10) << "Apple" << setw(8) << 1.1 << endl;     // 寬度只對下一個輸出有效
cout << setiosflags(ios::left) << ... << resetiosflags(ios::left);   // 靠左是「永久」的，要記得還原
cout << fixed << setprecision(1) << r;                      // 小數位數
cout << setfill('*') << setw(6) << 12;                      // 用 * 補滿
```

**函式多載 + 預設引數**
```cpp
void draw(int n = 1);
void draw(char ch, int n);
void draw(int s, int e, char ch = '*');
```
- 預設引數只能從右邊往左給；呼叫時若同時符合兩個版本會有「模稜兩可」的編譯錯誤。

## 常見失分點
- 類別宣告最後的分號 `};` 漏掉。
- 把題目要求的 `private` 成員寫成 `public`，或反過來少給必要的 `public`。
- `static` 成員只在類別內宣告，卻沒有在類別外定義，連結時會失敗。
- 運算子多載的回傳型別、`const` 與參照寫錯；數值在左邊的版本忘了 `friend`。
- 成員函式寫在類別外卻忘了 `類別名稱::`。
- `setiosflags(ios::left)` 設了沒還原，後面的輸出全部靠左。
