# 程式設計歷屆考題整理

大一上（C 語言）與大一下（C++ / BGI 繪圖）的歷屆上機考題，依「學期 / 屆別 / 第幾次考試」整理。

- 每題一個檔案：`p1`、`p2`……；`.jpg` 是題目附的輸出示意圖。
- 原檔是 Big5 編碼，已轉成 UTF-8 方便在 GitHub 閱讀；Visual Studio 若亂碼請另存為 Big5。
- 內容完全相同的檔案只留一份（例如 111屆的三份拷貝、同一份第二次考試的兩個來源）。
- 編譯產物（Debug、.obj、.exe、.vs）、專案檔、BGIKernel 圖形函式庫都沒有放進來。
- 部分考卷檔案含當時的作答，題目說明在每個檔案開頭的註解。
- 「年份未標」是來源資料夾沒寫屆別的考卷。
