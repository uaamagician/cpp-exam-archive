# 程式設計歷屆考題整理

大一上（C 語言）與大一下（C++ / BGI 繪圖）的歷屆上機考題，依「學期 / 第幾次考試 / 屆別」整理。

- 每題一個檔案：`p1`、`p2`……；`.jpg` 是題目附的輸出示意圖。
- 原檔是 Big5 編碼，已轉成 UTF-8 方便在 GitHub 閱讀；Visual Studio 若亂碼請另存為 Big5。
- 內容完全相同的檔案只留一份（例如 111屆的三份拷貝、同一份第二次考試的兩個來源）。
- 編譯產物（Debug、.obj、.exe、.vs）、專案檔、BGIKernel 圖形函式庫都沒有放進來。
- 部分考卷檔案含當時的作答，題目說明在每個檔案開頭的註解。
- 屆別：111屆、112屆；「2025屆」是 2025 年的考卷；「我們這屆」是來源沒寫屆別、確定是我們這屆的考卷（資料夾名稱帶 `_Ex`、`_A`、`_BGI`）。

## 怎麼讀

1. 先看題目：每個 `pN` 檔案開頭的註解就是題目、計分與參考輸出；有 `.jpg` 的題目是圖形輸出。
2. 想練習就把註解以下的程式碼蓋掉自己寫，寫完再對照。
3. 同一屆三次考試難度依序遞增；各屆題型相近，換屆時多半只改數字、範圍與圖形。

## 各部分的常見題型

**大一上 · C 語言**
- 第一次：變數與運算、`#define` 與 if/else 折扣計算、迴圈累加、自訂函式印圖形（金字塔）、字串處理
- 第二次：三數排序（不用暴力法）、`getchar` 計數字元、`switch` 猜拳、陣列、質數函式、`strlen` 字串比對
- 第三次：二維陣列、函式傳遞陣列、結構、巨集、遞迴（河內塔、陣列最大值）、巴斯卡三角形

**大一下 · C++ / BGI 繪圖**
- 使用 BGI 在視窗畫圖形（圓、線、動畫）、類別與運算子多載、檔案讀入座標、滑鼠事件
- 每個考卷共用 `functions.cpp` / `functions.h`（同內容只收一份，不重複放）
