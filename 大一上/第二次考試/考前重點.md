## 一定要會的語法

**三數比大小（非暴力法）**：先比兩個，再拿勝者跟第三個比，一共只需要 2～3 次比較。
```c
if (b > c) {
    if (c > a)      printf("b > c > a");
    else if (a > b) printf("a > b > c");
    else            printf("b > a > c");
} else {
    if (b > a)      printf("c > b > a");
    else if (c > a) printf("c > a > b");
    else            printf("a > c > b");
}
```

**`getchar` 讀一段文字，直到結尾符號**
```c
char ch;
int cntN = 0, cntSpace = 0, cntOther = 0;
while ((ch = getchar()) != '@') {          // 括號一定要加
    if (ch == 'n' || ch == 'N') cntN++;
    else if (ch >= '0' && ch <= '9') cntDigit++;
    else if (ch == ' ') cntSpace++;
    else if (ch != '\n' && ch != '\r') cntOther++;   // 換行不要算進「其他」
}
```
- 用 `switch` 分類字元時，每個 `case` 後面要加 `break;`。

**`switch` + 亂數**
```c
#include <time.h>
srand((unsigned)time(NULL));               // 只在程式開頭呼叫一次
int pc = rand() % 3 + 1;                   // 1~3
switch (me) {
    case 1: ...; break;
    case 2: ...; break;
    case 3: ...; break;
}
```
- 範圍亂數：`rand() % (max - min + 1) + min`，例如 100 到 300：`rand() % 201 + 100`。

**`do...while` 輸入驗證**
```c
do {
    printf("輸入 8 到 12 的偶數: "); scanf("%d", &n);
} while (n < 8 || n > 12 || n % 2 != 0);
```

**陣列**
```c
int f[20] = {0};
f[1] = f[2] = 1;
for (i = 3; i <= n; i++) f[i] = f[i-1] + f[i-2];
// 找最大最小
max = min = a[0];
for (i = 1; i < 10; i++) { if (a[i] > max) max = a[i]; if (a[i] < min) min = a[i]; }
```
- 不能用 `pow` 的級數：用變數連乘，例如 `term = term * 3.0f / 5;`。

**質數函式 + 每 N 個換行**
```c
int isP(int n) {
    int i;
    if (n < 2) return 0;
    for (i = 2; i * i <= n; i++) if (n % i == 0) return 0;
    return 1;
}
// 主程式
for (n = 500, cnt = 0; n <= 700; n++)
    if (isP(n)) { printf("%4d", n); if (++cnt % 7 == 0) printf("\n"); }
```

**因數與完全數**
```c
for (i = 1; i <= n / 2; i++) if (n % i == 0) { 因數個數++; sum += i; }
// 完全數：n == 它所有正因數（不含自己）的和，例如 6 = 1+2+3
```
- 因數的「積」很容易溢位，題目會提示用 `float` 或 `long long` 存。

**字串處理**
```c
// 找樣式 pat 在 str 中出現的位置
for (i = 0; i + plen <= slen; i++) {
    for (j = 0; j < plen && str[i+j] == pat[j]; j++) ;
    if (j == plen) { printf("%d ", i); cnt++; }
}
// 壓縮：aaaabbbccd -> a4b3c2d1，連續相同就累計，不同時就輸出前一個字元與次數
// 反轉：用兩個索引從頭尾往中間換；二進位字串：value = value * 2 + (s[i] - '0');
```

**陣列循環（permutation cycle）**：從 `i` 出發，一直走 `i = A[i]` 直到回到起點，過程輸出並記錄走過的格子（`visited[]`），每個循環只輸出一次，最後算「循環個數」與「平均長度」。

## 常見失分點
- 題目指定的語法沒用（例如要求 `switch`、`do...while`、不能暴力法、不能 `pow`）。
- `getchar` 的括號 `(ch = getchar()) != '@'` 寫錯。
- `srand` 放進迴圈，導致每次亂數都一樣。
- 質數判斷漏掉 `n < 2`，或迴圈起點寫成 0。
- 每 N 個換行忘了處理最後不滿一行的情況。
- 陣列邊界超出，或字串沒有 `'\0'`。

## 建議準備順序
1. `getchar` 統計 + `switch`（兩種寫法都練）。
2. 質數函式 + 每行 N 個，順便把因數、完全數練熟。
3. 三數比大小、陣列最大最小、費氏數列。
4. 字串樣式比對、壓縮、陣列循環（最難，留到最後）。
