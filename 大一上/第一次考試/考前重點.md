## 一定要會的語法

**輸入輸出與型別**
```c
int a, b;  float x;  char ch;
scanf("%d%d", &a, &b);       // 整數 %d、浮點數 %f、字元 %c、字串 %s（字串不加 &）
printf("%8.5f\n", x);        // 總寬 8、小數 5 位
float r = (float)a / b;      // 整數除法會捨去小數，要先轉型
```

**不能用 `pow`：自己連乘**
```c
z = x*x*x;                   // x 的三次方
```

**交換兩個變數（一定要暫存）**
```c
t = a;  a = b;  b = t;
```

**`#define` 常數（不加分號、不加 =）**
```c
#define TEA 40
```

**多重 if / else，條件組合**
```c
if (total >= 1200 && cups > 20)  ...     // 且
else if (a > 30 || b >= 25)      ...     // 或，混用時 || 要加括號
else ...
```
- 「超過」是 `>`，「超過（含）」是 `>=`。
- 整數折扣：先乘再除，`total * 9 / 10`；不要寫成 `total / 10 * 9`。
- 買 m 送 1：送的杯數 = `n / m`，實際杯數 = `n + n / m`。

**迴圈與取餘數**
```c
while (n <= 500) { if (n % 2 == 0 && n % 3 == 2) sum += n;  n++; }
```
- 累加用的變數一定先設 0；每個迴圈開始前起始值要重設；別忘了 `n++`。
- 偶數 `n % 2 == 0`、被 3 整除 `n % 3 == 0`、不能被 7 整除 `n % 7 != 0`。

**自訂函式（沒有回傳值、一個 int 引數）**
```c
void xp(int n) { while (n > 0) { printf("*"); n--; } printf("\n"); }   // 印 n 個 * 並換行
void xs(int n) { while (n > 0) { printf(" "); n--; } }                   // 印 n 個空白
```
- 函式寫在 `main` 前面，或先寫原型宣告 `void xp(int n);`。

**金字塔規律**（共 n 層，第 i 層）
- 正金字塔：空白 `n - i` 個、星星 `2*i - 1` 個
- 倒金字塔：空白 `i - 1` 個、星星 `2*(n-i) + 1` 個
- 菱形 / 沙漏：上半部畫 n 層，下半部從第 2 層開始畫，尖端那層只能印一次

**一元二次方程式**
```c
d = b*b - 4*a*c;
if (d > 0)       // 兩解 (-b ± sqrtf(d)) / (2*a)；記得 (float)(2*a)
else if (d == 0) // 一解 -b / (2.0f*a)
else             // 無解
```
- 要 `#include <math.h>`；a 可能是 0 時要先處理，避免除以 0。

**字元與字元陣列**
```c
char s[20];
s[len] = '\0';                 // 字串一定要以 '\0' 結尾
n = s[i] - '0';                // 字元 '7' 轉成數字 7（'0' 的 ASCII 是 48）
t = s[i]; s[i] = s[j]; s[j] = t;   // 交換
```
- 鏡射（頭尾對調）：`i = 0, j = len-1; while (i < j) { 交換; i++; j--; }`
- 長度可用 `strlen(s)`（要 `#include <string.h>`），也可以自己用 while 數到 `'\0'`。

## 常見失分點
- `scanf` 忘了 `&`、格式 `%d` / `%f` 用錯。
- 整數除法導致結果被捨去。
- 迴圈邊界多一次或少一次（尤其是字元陣列的 `s[i+1]`）。
- 沒有 `#include <math.h>` 就用 `sqrtf`。
- 輸出格式跟參考輸出差一個空白或換行。

## 建議準備順序
1. 先把 `xp` / `xs` 畫圖形練到不看講義也能寫。

3. 練二次方程式與字串交換。
4. 最後用各屆的考卷計時模擬，題目檔裡的註解就是考題。
