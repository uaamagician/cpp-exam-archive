## 一定要會的語法

**函式原型宣告（函式寫在 main 之後時必備）**
```c
void sort(int a[], int n);
void prnA(int a[], int n);
int  main(void) { ... sort(A, 8); ... }
void sort(int a[], int n) { ... }
```

**二維陣列：宣告時給初始值、用常數控制範圍**
```c
#define ROW 2
#define COL 3
int A[ROW][COL] = { {3, 2, 4}, {6, 1, 5} };
for (i = 0; i < ROW; i++) for (j = 0; j < COL; j++) C[i][j] = A[i][j] + B[i][j];
printf("%3d", C[i][j]);                       // 用寬度對齊
```
**傳二維陣列給函式：第二維的大小一定要寫**
```c
void genTT(int a[][SIZE + 1]);                // 乘法表加上「總和」那一列、一欄
```

**排序（由大到小的選擇或氣泡排序）**
```c
for (i = 0; i < n - 1; i++)
    for (j = 0; j < n - 1 - i; j++)
        if (a[j] < a[j+1]) { t = a[j]; a[j] = a[j+1]; a[j+1] = t; }
```

**結構**
```c
struct student { char name[12]; int chi, eng, math; float avg; };
struct student s;
scanf("%s", s.name);                           // 字元陣列不用 &
scanf("%d", &s.chi);
s.avg = (s.chi + s.eng + s.math) / 3.0f;
printf("%s %.2f\n", s.name, s.avg);
```
- 結構裡再放結構（`info.x`）、結構陣列（`cx[i].radius`）也會考。

**巨集（參數一定要加括號）**
```c
#define CUBIC(x)     ((x) * (x) * (x))
#define MIN(x, y)    ((x) < (y) ? (x) : (y))
#define DIFSQU(x, y) ((x) * (x) - (y) * (y))
```

**遞迴三要素：終止條件、縮小問題、回傳值**
```c
int hanoi(int n, int from, int to, int via) {      // 回傳搬動次數
    if (n == 0) return 0;
    int c = hanoi(n - 1, from, via, to);
    printf("將第 %d 個圓盤從塔 %d 搬到塔 %d\n", n, from, to);
    return c + 1 + hanoi(n - 1, via, to, from);
}
int findingMax(int a[], int n) {                   // 遞迴求陣列最大值
    if (n == 1) return a[0];
    int m = findingMax(a, n - 1);
    return m > a[n-1] ? m : a[n-1];
}
void toBinary(int n) { if (n > 1) toBinary(n / 2); printf("%d", n % 2); }   // 進位轉換
int  binomial(int n, int k) { return (k == 0 || k == n) ? 1 : binomial(n-1, k-1) + binomial(n-1, k); }
```

**cos 的泰勒展開（不能用 `pow`）**
```c
float fPower(float x, int n)  { float r = 1; while (n-- > 0) r *= x; return r; }
float fFactor(int n)          { float r = 1; for (int i = 2; i <= n; i++) r *= i; return r; }
float fCos(float x) {
    float s = 0;
    for (int n = 0; n <= 8; n++)
        s += (n % 2 ? -1 : 1) * fPower(x, 2*n) / fFactor(2*n);
    return s;
}
// 主程式：fCos(角度 * (3.1415926f / 180.0f))，角度要先換成弧度
```

**巴斯卡三角形**：`C[i][j] = C[i-1][j-1] + C[i-1][j]`，每個數字用固定寬度 `%4d` 輸出，每一層前面補 `(n-i)*2` 個空白才會對齊成三角形。

## 常見失分點
- 用了全域變數；原型宣告漏寫；迴圈終止條件寫死 `3` 而不是 `COL`。
- 傳二維陣列時沒寫第二維大小，編譯就會出錯。
- 巨集參數沒括號，`CUBIC(a+1)` 結果會錯。
- 遞迴沒有終止條件，或次數不是由函式回傳值算出來（題目常要求「搬動次數必須來自 `Hanoi` 的回傳值」）。
- `fCos` 傳入的是角度而不是弧度。

## 建議準備順序
1. 先寫排序、二維陣列相加、乘法表，把「函式傳陣列」熟練。
2. 遞迴三題必練：河內塔、陣列最大值、進位轉換。
3. 結構與巨集（內容少、很好拿分）。
4. 泰勒展開與巴斯卡三角形放最後。
